About Lower Esopus Monitoring

This site brings together monitoring information from stations along the Lower Esopus. Use it to explore flow and water-quality observations, compare measurements over time, and download the displayed records.

How to use the data

  1. Open the Monitoring Data section.
  2. Select a station marker on the map.
  3. Choose flow or water-quality data from the marker menu.
  4. Choose a graph time frame, review the charts, or download the records as a CSV file.

Understanding the views

Flow data is shown as a single time-series chart. Water-quality data can contain several measurements; use the checkboxes to choose which values appear in individual charts.

Data note

Monitoring records are loaded from the program’s connected data source. Availability and reporting frequency may vary by station and measurement.
